# My Notes

**1: Clone project**
- `$ git clone git@github.com:pablocevalenzuela/poc_ecomm_support_back_office_agent_v1.git`

**2: Set up virtual environment Python**
- `$ cd poc_ecomm_support_back_office_agent_v1/`
- `$ git init`
- `$ python --version`
- `$ python3.14 -m venv venv`
- `$ source venv/bin/activate`

**3: Set up of same application**
- `$ pip install -r requirements.txt`

**4: Localhost application deploy (using Makefile)**
- `$ make dev`
